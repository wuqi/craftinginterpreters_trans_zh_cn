# 第21章 critique（只诊断，首轮）

## (i) 准确性 / 漏字

- 逐段对照原文，未见漏译：语义回顾、语句/声明文法、栈效应、错误同步、
  `var` 声明、读/写全局、`canAssign` 修优先级坑、给所有解析函数加参数。
- 代码块内注释 `// Error.` → `// 错误。`（沿用 ch15 手写块注释译法）；程序输出保留。

## (ii) 流畅度 / 人称（第 5 条硬规则）

- 「它从字节码块里读出…」（`READ_STRING` 宏）→「这个宏从字节码块里读出…」
- 「它会调用这个新的解析函数：」→「这里会调用这个新的解析函数：」
- 「它调用前面同一个 `identifierConstant()`…」→「这个函数调用…」
- 「它边解析边生成字节码…它一认出一段语法…」→「编译器边解析边生成…一认出一段语法…」
- 「它只关心优先级够不够低…」（`variable()`）→「这个函数只关心…」
- 「它通过一个新参数把它传下去：」→「再通过一个新参数把它传下去：」

## (iii) 风格

- 调侃全保留：没那么多智识架子、一层套一层全是 helper、「对得起自己的存在」、
  语言展览会 4H `moo`/`baa`、`a * b` 当赋值目标的脑补、一堆苦力活、「呼！」。
- 强调标记全 `**粗体**`：`*global*`→**全局**、`*slow*`→**慢**、`*print*`→**print**、
  `*execute*`→**执行**、`*problems*`/`*solutions*`→**问题**/**解法**、`*do*`→**do** 等。

## (iv) 术语 / 结构

- 结构数字全对：aside 16/16、span 15/15、img 4/4、`## ` 5/5、`### ` 3/3、div 1/1、
  `^code` 54/54 行逐字一致、`name` 值集合一致（`delete` 仅 aside）。
- 链接：`[hash]`、`[next chapter]`、`[functions]`、`[errors]`、`[implicit]` 均在。
- `-- `→`——`；省略号 `……`；`<aside name="nil" class="bottom">` 属性保留。
