# 第16章 critique（只诊断，未修）

## (i) 准确性

- 「内存也翻腾得厉害」：`memory churn` 直译尚可，保留。
- 「它跟 jlox 的版本几乎一模一样」中 `It's virtually identical`——`它` 指 `number()`，改主语。
- 「它就会自动为你生成一个 DFA」——`it` 指 Lex，改为「Lex 就会……」

## (ii) 流畅度 / 人称（第 5 条硬规则）

以「它」作主语指代**代码/函数**的句子，必须改（中文里指代代码极不自然）：

- 它无需动态分配任何东西 → 扫描器无需……
- 它让扫描器越过所有前导空白 → 这个调用让……
- 它算是一个独立的小型扫描器。它循环…… → 这算是……循环着……
- 它仅仅返回当前字符 → 这个函数只是返回……
- 它跟 `peek()` 类似 → 这个函数跟 `peek()` 类似……
- 它会调用一个新函数 → 这里会调用……
- 它跟 jlox 类似，我们不断消费字符 → 跟 jlox 类似……
- 它跟 jlox 的 Token 类很像 → clox 的 Token 跟 jlox 的 Token 类很像
- 它用扫描器的……它有个姐妹函数…… → 这个函数用……另有一个姐妹函数……
- 它只做检测关键字所需的最小工作 → 这段代码只做……

## (iii) 风格

- 「嗯，是那个大小**再加一**。」与「**寒酸**」符合口语；保留。
- 「那坨代码」对应 `that blob of code`，保留。
- eins：「它」过多的问题同 (ii)。

## (iv) 术语 / 结构

- `one` span 原文包住 `size`，初稿包成「大」，改为「大小」。
- `outlive` span 原文包住 `outlives`，改为包住「活得久」。
- `Lex` 两处 `[Lex][]` 保留英文与隐式引用键 `lex`。
- 链接 `[从零开始搭自己的哈希表][hash]`、`[**字典树（trie）**][trie]`、
  `[**语法图**][syntax diagram]` 均为具名引用（中文文本不可用 `[]`）。
- 程序输出块、`^code`、aside/span 的 `name` 值原样保留。

## 待润色（Polish）

- 「我们读取文件，然后执行读出来的那串 Lox 源代码」顺。
- 「热切地/急不可耐」取舍：`eagerly` → 急不可耐。
