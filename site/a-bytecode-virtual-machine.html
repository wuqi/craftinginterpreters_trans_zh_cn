III

第二部分 字节码虚拟机

我们的 Java 解释器 jlox，教会了我们编程语言的一大批基础。可要学的东西还有很多。首先， 只要你在 jlox 里跑几个有点意思的 Lox 程序，就会发现它慢得让人难受。它采用的解释方式—— 直接遍历 AST——对某些实际用途来说够用了，但对一门通用的脚本语言而言，就差得远了。

另外，我们还在一定程度上依赖着 JVM 自身的运行时特性。我们想当然地认为，Java 里的 instanceof 这类东西不知怎么就能用。而且我们从没为内存管理操过一秒钟的心，因为 JVM 的垃圾回收器 替我们打点好了一切。

当我们把注意力放在高层概念上时，把这些轻轻带过没问题。可既然我们已经摸清了它的门路， 就该往下深入到更低的层次，仅凭 C 标准库，从零搭起我们自己的虚拟机……
